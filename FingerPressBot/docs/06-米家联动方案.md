# 06 - 米家联动方案（可选阶段，后期实施）

> 本文档是米家接入的**调研结论 + 实施方案**。
> 你已选择"暂缓米家部分"，本方案保留备用；需要时按文档操作即可（预计 1 小时）。
> 前提：核心功能（阶段 1~5）已完成验收。

---

## 一、调研结论：个人 DIY 接入米家的可行路径分析

| 路径 | 可行性 | 说明 |
|---|---|---|
| 米家开放平台（IoT 开发者平台） | 不可行 | 仅面向企业：需营业执照入驻、产品过认证实验室检测（3C/SRRC/入网许可）、送审上线流程，个人无法走通 |
| Blinker/点灯科技第三方中转 | 不可行 | **该服务于 2025-07-01 正式下线**（平台要求音箱产品 3C 认证），DIY 设备无法再经此出现在米家/小爱 |
| 小爱同学技能开放平台 | 不可行 | 仅对企业开发者开放 |
| Home Assistant 桥接 | 方向不符 | HA 可以把"米家设备接入 HA"，但**反向**（让 DIY 设备出现在米家 APP）无官方通道；且需额外部署 HA 主机，学习成本高 |
| **米家智能插座 + 通电触发** | **可行（本方案采用）** | 不依赖任何开放平台：米家自动化控制插座通断，机器人检测到"上电"即执行一次按压 |

**结论**：让 DIY 设备直接出现在米家 APP 设备列表，个人开发者目前无路可走。
米家联动采用"**插座通电触发**"模式——米家 APP 里控制的是插座，用户感知上等价于"用米家触发一次按压"，且**定时、到家触发等自动化全部可用**。

---

## 二、方案架构

```
米家 APP（手动/定时/自动化）
        │ 控制通断
        ▼
米家智能插座（WiFi 版）──── 220V 通断 ──── 机器人的 5V/2A 充电头
                                                │
                                                ▼
                                        ESP32 检测上电
                                                │
                                                ▼
                                        执行一次按压（上电自动按压模式）
```

**触发逻辑**：米家让插座"断电 → 通电"一次 = 机器人执行一次按压。
（只要固件开启"上电自动按压"开关 V5，每次冷启动自动按一次。）

---

## 三、硬件准备

| 物品 | 规格 | 说明 |
|---|---|---|
| 米家智能插座 2/3（WiFi 版） | 官方渠道，约 40~60 元 | 认准 WiFi 版（蓝牙版无法远程定时） |
| 5V/2A 充电头 + 数据线 | 现有即可 | 插在米家插座上给机器人供电 |

接线：**充电头 → 米家插座 → 机器人的 USB 线**（电源链串联，无其他改动）。

---

## 四、固件配置（2 分钟）

1. 固件已内置"上电自动按压"功能（开关 V5，默认关）；
2. 手机 Blynk APP 把 **V5 开关打开**；
3. 验证：拔掉机器人电源 → 重新插上，设备启动约 3 秒后应自动按压一次；
4. 确认无误后再接入米家插座（避免米家配置时误触发多次）。

> 参数说明：
> - 上电后延迟 3 秒按压（等待 WiFi/舵机初始化完成）；
> - 每次冷启动只按一次；
> - 关闭 V5 即恢复"仅手动按压"模式，互不影响。

---

## 五、米家 APP 配置步骤

### 5.1 添加插座

1. 米家 APP → 右上角 + → 添加设备 → 找到插座型号 → 按提示配网（2.4G）；
2. 插座起名：**"按压机器人电源"**（方便识别）。

### 5.2 手动触发（即时按压）

米家 APP 中操作插座：**关闭 → 再打开**，机器人即按压一次。
（连续操作间隔 ≥10 秒，给机器人留断电/启动时间。）

### 5.3 自动化一：定时按压（如每天早上开机）

米家 APP → 智能 → 右上角 + → 新建自动化：

```
触发条件：定时 → 每天 07:00
执行动作：关闭 "按压机器人电源"
再添加：等待 5 秒后 → 打开 "按压机器人电源"
```

> 说明：米家的"等待"动作在部分版本中位于"延时"或需要两条自动化：
> 方案 B（两条自动化）：
> - 自动化 1：每天 07:00 → 关闭插座
> - 自动化 2：每天 07:05 → 打开插座（5 分钟间隔更稳妥，避免指令冲突）

### 5.4 自动化二：到家自动触发（如开门自动按开机键）

需要米家人体传感器或门窗传感器（约 30~60 元，或家里已有）：

```
触发条件：门窗传感器"打开"（或人体传感器"有人移动"）
执行动作：关闭 "按压机器人电源" → 延时 → 打开
```

### 5.5 自动化三：倒计时联动（进阶）

米家 APP 中插座支持**倒计时关闭**：临时出门时设"5 分钟后关"，回家点开插座即触发按压——灵活组合，不限于以上示例。

## 六、米家联动验收清单

| 测试项 | 方法 | 通过标准 |
|---|---|---|
| 上电自动按压 | 插座开→关→开 | 每次通电后 3~5 秒内按压一次 |
| 手动触发 | 米家 APP 关/开插座 | 同上 |
| 定时触发 | 设 2 分钟后定时 | 到点自动执行一次按压 |
| 传感器触发 | 触发门磁/人体传感器 | 自动化链完整执行 |
| 断电恢复 | 插座断电期间机器人完成按压动作 | 按压动作完成后再断电，避免动作中断（见注意事项） |

---

## 七、注意事项与易错点

1. **触发机制局限**：每次触发 = "断→通"循环。米家"定时开"单独动作无法重复触发（插座若已处于开状态，就没有"上电沿"）；务必按 5.3 的"关→开"或"关→延时→开"配置。
2. **米家 APP 显示的是插座**：米家设备列表里看到的是"按压机器人电源"插座，不是机器人本体——这是个人 DIY 的限制，属预期行为。
3. **掉电保护**：插座断电瞬间若机器人正在按压，动作会中断（舵机停在半途）。建议：
   - 触发间隔 ≥10 秒，且避免在机器人刚动作时立刻断电；
   - 固件已做"上电后自动回位"（舵机初始化回待机角），下次上电自动归位，不会卡死。
4. **WiFi 双重依赖**：米家自动化 → 米家云；机器人 → Blynk 云 + 本地 WiFi。家庭断外网时米家自动化不可用，属正常。
5. **安全**：米家插座建议选择带"过载保护"的型号；机器人电源链路上不要并联其他大功率电器。
6. **电梯按钮合规提醒**：电梯外呼按钮属公共设施，私自安装按压装置涉及公共安全与合规问题（紧急情况可能影响乘梯安全），本方案不推荐用于电梯，仅适用于家庭自有设备（电脑、门铃、开关等）。

## 八、进阶扩展（阶段 7 备选）

- **电池供电**：底座配重仓内放 18650×2 + 5V 升压模块（MT3608），实现断电续航，配合米家插座可实现"停电也能完成按压"；
- **多按键**：第二路舵机（GPIO12）可扩展为双按压机构，Blynk 面板增加 V6 按钮；
- **按压反馈**：若目标设备有可观测状态（如台灯电流），可加装电流传感器，按压后自动校验是否生效（进阶玩法）。
