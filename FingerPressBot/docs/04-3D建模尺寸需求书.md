# 04 - 3D 建模尺寸需求书（你的建模依据）

> 本文档是**你负责的部分**：按此建模并 3D 打印全部结构件。
> 所有尺寸均为**设计基准值**；其中标注"需实测"的数据，请用游标卡尺测量**你到手的实物**后以实测为准。
> 材料：PLA 即可（摇臂、按压头建议 PETG 更耐疲劳）；壁厚 ≥2mm；打印填充率 40% 以上（结构件）。

---

## 一、装配总览

```
          ┌────────────────────────┐
          │     舵机仓（部件3）      │ ← 里面装 MG90S 舵机
          │     输出轴朝右          │
          │   ┌──────┐             │
          │   │ 舵机  │═══▶ 按压臂(部件2)──▶ 按压头(部件1)──▶ 按键
          │   └──────┘             │
          └────────┬───────────────┘
                   │ 插接/螺丝
          ┌────────┴───────────────┐
          │     立柱（部件4）        │ ← 高度可选：60 / 80 / 100mm
          └────────┬───────────────┘
                   │ 插接
          ┌────────┴───────────────┐
          │     底座（部件5）        │ ← 100×100mm，含配重仓
          └────────────────────────┘
                （底面贴 3M 胶或放配重，固定于按键旁）
```

**安装尺寸链**（决定按压头能否对准按键）：

```
按压头接触面高度 = 底座高度 + 立柱高度 + 舵机输出轴中心高度
目标按键高度范围：台式机电源键离桌面约 150~450mm（机箱顶部/前面板）
```

- 舵机输出轴中心到舵机底面距离：**约 14mm**（需实测，记为 `H_servo`）；
- 需要的立柱高度 ≈ 按键高度 − 底座高 − H_servo − 按压臂厚度/2。

## 二、部件清单（共 5 件 + 2 个备件）

| 编号 | 部件 | 数量 | 功能 | 打印材料 |
|---|---|---|---|---|
| 1 | 按压头（平头 + 凸头两种） | 各 1 | 接触按键，缓冲防损伤 | PETG + 硅胶垫 |
| 2 | 按压臂 | 1 | 把舵机旋转变成按压动作，多档力臂 | PETG |
| 3 | 舵机仓 | 1 | 固定 MG90S 舵机 | PLA/PETG |
| 4 | 立柱（60/80/100mm 三档） | 各 1 | 支撑高度可调 | PLA |
| 5 | 底座 | 1 | 配重 + 安装立柱 + 走线 | PLA |
| — | 舵盘延长座（备选） | 1 | 如果不想用按压臂插轴方案 | PETG |

> 说明：**按压臂建议固定在舵机自带舵盘上**（舵盘随机附送，塑料十字盘），通过 2 颗 M2 螺丝连接——这样不需要打印高精度十字轴孔，装配最简单、最可靠。按压臂与舵盘之间的连接孔用**腰形长孔**设计，适配不同批次舵盘的孔距（无需精确实测）。

## 三、部件 1：按压头（直径 10mm）

**平头版**（按压凸起的键帽，如台式机电源键）：

```
        ┌──────┐
        │ 开槽 │ ← 顶部十字/一字槽，方便螺丝刀拧入调节高度
        ├──────┤
        │ 圆柱  │ 高 15mm，直径 10mm
        │ M3 通孔│ ← 中心贯穿 M3 光孔（穿 M3×25 螺丝）
        ├──────┤
        │ 平底面 │ ← 底面粘硅胶脚垫（直径 10~15mm 带背胶）
        └──────┘
```

**凸头版**（按压齐平/内凹按键，如某些嵌入式开关）：

```
        ┌──────┐
        │ 开槽  │
        ├──────┤
        │ 圆柱  │ 高 15mm
        │ M3孔  │
        ├──────┤
        │  ╲凸点│ ← 底部中心凸出半球，直径 6mm、凸出 3mm（伸进键帽凹槽）
        └──────┘
```

- 通孔直径 3.2mm（M3 螺丝过孔），压入 M3 螺母（热熔螺母 M3×5×4）则更牢；
- 硅胶脚垫用 3M 背胶直接贴底面，**它是保护按键的关键缓冲件**，务必使用。

## 四、部件 2：按压臂（长 38mm 平板）

```
    ┌──────────────────────────────────┐
    │  M2腰形孔 ×2       M3圆孔(3档)    │
    │  ┌────┐              ○   ○   ○   │
    │  │    │              │   │   │   │
    │  └────┘              ↓   ↓   ↓   │
    │ ←───→  38mm                   R=10 12 15mm
    └──────────────────────────────────┘
    厚 3mm，宽 12mm
```

| 特征 | 规格 | 说明 |
|---|---|---|
| 外形 | 38 × 12 × 3mm | 平板 |
| 近轴端 | **2 个 M2 腰形孔**：宽 2.2mm、长 6mm，两孔中心距 8mm | 适配舵盘任意孔距（舵盘孔距需实测，腰形孔兜底） |
| 远端 | **3 个 M3 圆孔**（直径 3.2mm），距轴心 R = 10 / 12 / 15mm | 三档力臂：**R 越大，行程越大、力度越小** |
| 参考标记 | 远端刻线标 R10/R12/R15 | 方便识别 |

**行程与力度计算公式（软件 + 结构联调）**：

- 按压行程 = 角度差（度）× R × π / 180
  - R=12mm、角度差 25° → 行程 ≈ 5.2mm（默认设计值）
  - R=12mm、角度差 15° → 行程 ≈ 3.1mm（小行程档）
- 按压头安装孔选 R=12 为默认（行程 3~5mm 覆盖），R=15 适合需要更小力度（键程长）的按键，R=10 适合键程短的按键。

## 五、部件 3：舵机仓（关键配合件）

**MG90S 参考尺寸（需实测核对）**：

```
外形：长 22.8 × 宽 12.2 × 高 28.5 mm（高含输出轴段）
安装孔：4 × M2 通孔（孔径 2.2mm），四角分布，孔距以实测为准
输出轴：直径 4.8mm 花键轴，伸出高度约 4mm（需实测）
输出轴中心到舵机底面：约 14mm（需实测，记为 H_servo）
```

**舵机仓设计**：

```
俯视（输出轴朝右）：
┌─────────────────────────────┐
│  ┌───────────────────────┐  │
│  │   舵机内腔（开一面）    │  │ ← 内腔 24 × 13.5 × 30mm（留 0.5~0.7mm 间隙）
│  │   M2柱 ×4             │  │ ← 四角 M2 热熔螺母柱，与舵机安装孔对齐
│  └──────────┬────────────┘  │
│   ┌─────────┴─────────┐      │
│   │ 轴孔 φ6（输出轴孔） │      │ ← 侧壁开 φ6 圆孔让输出轴伸出
│   └───────────────────┘      │
└─────────────────────────────┘
```

| 特征 | 规格 | 说明 |
|---|---|---|
| 内腔 | 24 × 13.5 × 30mm | 外形参考 22.8×12.2×28.5，四周留 0.5~0.7mm 间隙（打印公差） |
| 固定 | 四角 M2 热熔螺母（M2×4×3.5）+ M2×8 螺丝 | 与舵机四角安装孔对齐（孔位实测后建模） |
| 输出轴孔 | φ6 圆孔，位于侧壁中心 | 让舵机轴伸出，轴心高度 = 内腔底面 + H_servo |
| 走线槽 | 侧壁开 8×4mm 槽 | 舵机三根线引出 |
| 底部 | 中央 φ12 圆孔 | 立柱插接（与立柱顶面凸台配合） |
| 安装方向 | 四向可转（90° 步进）：底部 4 个插接槽或螺丝孔呈十字分布 | 让按压方向可旋转，适应不同按键朝向 |

## 六、部件 4：立柱（60 / 80 / 100mm 三档）

```
     ┌──────────┐
     │ 顶面凸台  │ ← φ12 凸台，高 8mm（插入舵机仓底孔）
     ├──────────┤
     │          │
     │  中空柱   │ ← 方形中空柱 20×20mm 外径，壁厚 2mm
     │          │
     ├──────────┤
     │ 底面凸台  │ ← φ12 凸台，高 8mm（插入底座）
     └──────────┘
```

- 三档高度：**60 / 80 / 100mm**（从底面到顶面），打印 3 根备用；
- 内部中空：**穿线孔**（USB 线从底座穿到舵机仓）；
- 中空内径 ≥ φ10，保证 USB 头可穿过；
- 凸台与孔配合间隙 0.3mm（插拔顺畅不晃动），配合处可加 M3 侧向锁紧螺丝孔（φ3.2 通孔 + M3 热熔螺母）。

| 配重仓 | 内腔 80×80×25mm，顶面盖板（卡扣或 M3 螺丝） | 放铁块/铅块/废旧螺丝，**配重 ≥300g**（防翻倒）；或改放 18650 电池（阶段 7 扩展） |

- **粘贴固定**（推荐机箱侧面/按键旁平整面）：配重仓可空着，底面直接贴 **3M VHB 双面胶**（强力、可撕下不留残胶）。

## 八、建模与打印规范

1. **公差策略**：所有配合面（凸台/孔/插槽）间隙 0.2~0.3mm；孔位先用卡尺实测实物再建模；
2. **打印参数**：层高 0.2mm、壁厚 ≥2mm、填充 40%（舵机仓 60%）、支撑按需（舵机仓侧壁开孔需支撑）；
3. **热熔螺母**：M2×4×3.5（舵机仓）、M3×5×4（按压头/立柱/底座），烙铁 230℃ 压入；
4. **先打底座+立柱+舵机仓试装配**，确认舵机能放入、按压臂能自由转动，再打其余件；
5. **首版验证**：按压臂先打 R=12 档，配合固件默认角度（35°），实测行程后再决定是否换档。

## 十、易错点汇总

1. **孔位以实测为准**：网上尺寸图与实物常有 0.5mm 级差异，卡尺实测是唯一可靠途径；
2. **间隙留足**：舵机仓内腔留 0.5~0.7mm，太紧会顶坏舵机塑料壳；
3. **按压臂固定用舵盘**：不要打印十字轴孔直接插舵机轴（打印公差难控制，易松旷），用随机舵盘 + M2 螺丝；
4. **按压头必须有缓冲**：硅胶垫/热缩管不可省，金属直接顶按键会损伤键帽；
5. **配重别省**：桌面放置必须 ≥300g，否则按压反力会把整机顶翻；
6. **穿线空间**：立柱中空 ≥φ10，USB 头才能穿过去；
7. **先试装再全打**：先打底座/立柱/舵机仓试装，确认配合后再批量打印。
