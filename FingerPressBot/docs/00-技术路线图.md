# 手指按压机器人（FingerPressBot）技术路线图

> 本文档是项目的总体路线图存档，包含方案选型、阶段划分、依赖关系与风险清单。配套文档按阶段逐步交付。

## 一、项目目标

制作一台"手指按压机器人"：通过手机 APP 远程控制它执行一次"按压"动作，用于按下电脑开机键、门铃、开关等目标按键。后期可选接入米家智能插座，实现米家 APP 定时/自动化联动。

**你的分工**：仅负责 3D 建模与打印（依据 `04-3D建模尺寸需求书.md`）。
**我的分工**：硬件选型、电路接线、固件开发、Blynk 配置、联调验收，全程逐步指导。

## 二、总体架构

```
手机 Blynk APP ──云──▶ ESP32 (WiFi 2.4G) ──PWM──▶ MG90S 舵机 ──摇臂──▶ 按压目标
手机浏览器    ──局域网─▶ (备用状态页)              │
USB 5V/2A 充电头 ──供电──┘（后期可选：米家智能插座控制该电源实现米家联动）
```

## 三、关键技术选型（已定案）

| 部件 | 型号 | 选型理由 |
|---|---|---|
| 主控 | ESP32 DevKitC V4（WROOM-32E） | WiFi 2.4G、Arduino 生态成熟、资料最多 |
| 执行机构 | MG90S 舵机（金属齿，22.8×12.2×28.5mm，扭矩约 2.0kg·cm） | 力度/行程可通过角度与摇臂长度软件化调节；备选 MG996R（更大力） |
| 电源 | 5V/2A USB 充电头 + 数据线 | 舵机峰值电流约 1A，电源必须 2A 以上；后期可扩展 18650 电池 |
| 手机控制 | Blynk IoT APP（免费版） | 拖拽式面板 + 扫码配网，非开发者零门槛 |
| 米家联动（后期可选） | 米家智能插座 2/3 + 通电触发 | 个人 DIY 接入米家的唯一可靠路径 |

## 四、米家接入可行性结论（已调研，2026-08）

| 路径 | 结论 |
|---|---|
| 米家开放平台（IoT 开发者平台） | 仅面向企业，需营业执照 + 认证实验室检测（3C/SRRC 等）+ 送审，个人不可行 |
| Blinker/点灯科技第三方中转 | 已于 2025-07-01 下线（平台要求 3C 认证），个人 DIY 无法再接入 |
| 小爱同学技能开放平台 | 仅对企业开发者开放 |
| **米家智能插座 + 通电触发（本方案）** | **唯一可靠路径**：米家自动化控制插座通断 → 机器人上电自动按压一次 |

## 六、默认设计参数（供确认）

- 按压目标：标准台式机电源键等家庭场景按键；按压行程 3~5mm、力度 1~3N，均可调节
- 供电：优先 USB 5V/2A，可扩展电池方案
- 通信：WiFi 2.4GHz
- 安装方式：桌面放置（配重底座 ≥300g）或固定于按键旁

## 七、贯穿全程的风险与提醒

1. **米家认证限制**：个人 DIY 设备无法出现在米家 APP 设备列表中，米家联动只能是"智能插座通电触发"模式（米家 APP 中控制的是插座）。
2. **按压力度过大**：默认 1~3N，从最小角度逐步校准；按压保持时间默认 400ms，勿调大（长按 4 秒会触发电脑强制关机）。
3. **WiFi 稳定性**：使用 2.4G 专用 SSID，固件自动重连，断网时本地状态页可用。
4. **电源电流**：舵机峰值约 1A，务必使用 5V/2A 电源；不要用电脑 USB 口长期供电。
5. **电梯按钮合规**：电梯外呼按钮属公共设施，私自安装涉及合规问题；本设计默认家庭场景（电脑开机键、门铃、开关等），电梯场景仅作结构适配参考。
6. **Blynk 免费版限制**：5 台设备 / 2000 能量点（本项目 1 台设备足够）；海外云偶发延迟属正常，固件自带自动重连。
7. **3D 打印公差**：舵机安装孔位先卡尺实测到手舵机再建模，预留 0.2~0.5mm 间隙。
