# 03 - Blynk 配置指南

> 本文档覆盖**阶段 1（开发环境 + 账号）**和**阶段 3（APP 控制联调）**。
> 全程图形界面操作，不需要写代码。

---

## 第一部分：开发环境安装（阶段 1，约 40 分钟）

### 1.1 安装 Arduino IDE 2.x

1. 打开官网 https://www.arduino.cc/en/software 下载 **Arduino IDE 2.x**（Windows 版）；
2. 安装时全部默认选项，装完打开（界面可选中文：**File → Preferences → 语言** 选中文，重启）。

### 1.2 安装 ESP32 开发板支持包

1. 菜单 **文件 → 首选项**，找到"附加开发板管理器网址"，粘贴：

```
https://espressif.github.io/arduino-esp32/package_esp32_index.json
```

2. 点确定；然后 **工具 → 开发板 → 开发板管理器**；
3. 搜索框输入 `esp32`，找到 **esp32 by Espressif Systems**，点**安装**（选最新版，约 200MB，需要几分钟，等它下载完）；
4. 安装完成后，**工具 → 开发板** 菜单里应能看到 `esp32` 分类。

### 1.3 安装两个库

1. 菜单 **工具 → 管理库**（左侧书本图标）；
2. 搜索 **Blynk**，安装作者为 **Volodymyr Shymanskyy** 的最新版（v1.x，注意不是老版 Blynk Legacy）；
3. 搜索 **ESP32Servo**，安装作者 **Kevin Harrington** 的最新版。

### 1.4 连线检查（可选）

USB 线连接 ESP32 到电脑，**工具 → 端口** 应出现一个新端口（如 `COM3`）。没有则参考 `02-接线与焊接指南.md` 的驱动排查。

## 第二部分：Blynk 账号与设备模板（阶段 1，约 20 分钟）

### 2.1 手机安装 Blynk APP

- 应用商店搜索 **Blynk IoT**（图标是**蓝色闪电**）并安装；
- 打开 APP，**注册账号**（邮箱注册即可，需要收验证码）；
- 用同一个账号在电脑浏览器打开 https://blynk.cloud 登录（后面用）。

> 重要：不要下载旧版 "Blynk"（灰色闪电，Legacy 版已停止服务）。

### 2.2 创建设备模板（在电脑网页操作）

1. 登录 blynk.cloud，左侧菜单 **Developer → Templates → New Template**（新建模板）；
2. 填写：
   - **Name**：`FingerPressBot`
   - **Hardware**：选 `ESP32 Dev Board`（或 ESP32 DevKit）
   - **Connection Type**：`WiFi`
3. 点 **Create** 创建；
4. 创建后进入模板详情页，复制 **Template ID**（形如 `TMPL3xxxxxxxxxx`），**稍后填入固件代码**。

### 2.3 把 Template ID 填进固件

1. 用 Arduino IDE 打开 `firmware/FingerPressBot/FingerPressBot.ino`；
2. 找到文件顶部配置区：

```cpp
#define BLYNK_TEMPLATE_ID "TMPL000000000000"   // ← 改成你复制的 Template ID
```

3. **保存文件**（Ctrl+S）。

---

## 第三部分：编译烧录（衔接阶段 2）

1. **工具 → 开发板 → esp32 → ESP32 Dev Module**；
2. **工具 → 端口** 选择 ESP32 所在端口；
3. 点**上传**（右箭头），首次编译约 2~5 分钟；
4. 烧录成功后打开**串口监视器**（波特率 115200），应看到：

```
=== FingerPressBot boot ===
[wifi] local IP: 192.168.x.x
[web]  http://192.168.x.x  (兜底控制页)
```

> 首次上电如果还没配网，Edgent 模式会进入配网状态（等待手机配网），串口会提示相关日志，属正常。

---

## 第四部分：手机配网（阶段 3 第一步，5 分钟）

设备首次使用（或换了 WiFi）需要配网，**全程在手机 APP 操作，不用改代码**：

1. 确保手机连接的是 **2.4G WiFi**（路由器若开了"双频合一"，先到路由器后台关闭，或手机开一个 2.4G 热点备用）；
2. 打开手机 Blynk APP，点击右上角 **+ → Add New Device**；
3. 选择模板 **FingerPressBot**（或搜索模板名），点继续；
4. APP 提示搜索设备/扫码：此时设备处于配网状态（新烧录的设备开机即进入配网模式；如果已经配过网，需要**按住 ESP32 的 BOOT 键再通电 3 秒**强制进入配网模式）；
5. APP 找到设备后，选择你的 2.4G WiFi 并输入密码；
6. 等待 30 秒左右，设备上线，APP 显示 **Online**；
7. 串口监视器会打印 `[wifi] local IP: ...`，说明配网成功。

## 第五部分：创建控制面板（阶段 3 第二步，15 分钟）

### 5.1 进入设备面板编辑器

- APP 中点击设备卡片进入控制页 → 点右上角**铅笔图标**（编辑模式）；
- 拖拽以下组件并配置：

### 5.2 组件配置表

| 组件 | 数据流(引脚) | 配置要点 | 用途 |
|---|---|---|---|
| **Button 按钮** | V0 | 模式选 **Switch**；`PUSH`（按下时发 1，松开发 0） | 按压一次 |
| **Slider 滑杆** | V1 | 范围 **15 ~ 90**，步长 1，默认 35 | 按压角度（行程）调节 |
| **Slider 滑杆** | V2 | 范围 **100 ~ 2000**，步长 50，默认 400 | 按压保持时间（毫秒） |
| **Label 标签** | V3 | 自动接收设备状态文本 | 状态显示（就绪/按压中/间隔锁中） |
| **Label 标签** | V4 | 自动接收按压次数 | 按压计数 |
| **Switch 开关** | V5 | 开=1 关=0，默认关 | 上电自动按压（米家联动预留） |

> 数据流（Datastream）可以在 blynk.cloud 模板的 **Datastreams** 页预先创建，也可以直接在 APP 拖组件时自动创建（选择 V0~V5 对应引脚即可）。

### 5.3 面板布局建议

```
┌────────────────────────────┐
│   FingerPressBot  [在线]    │
│   ┌──────────────────────┐ │
│   │     按压（大按钮）     │ │  ← Button V0
│   └──────────────────────┘ │
│   按压角度   ──────●────   │  ← Slider V1
│   保持时间   ──────●────   │  ← Slider V2
│   状态: 就绪   按压次数: 0  │  ← Label V3 / V4
│   上电自动按压 [关]         │  ← Switch V5
└────────────────────────────┘
```

## 第六部分：联调测试（阶段 3 第三步）

### 6.1 空载测试（不接触真实按键）

1. 舵机上先装好**舵盘**（随机附送，插在花键轴上），方便观察；
2. 手机 APP 点"按压"按钮：
   - 舵盘应快速转到按压角 → 保持约 0.4 秒 → 回到待机角；
   - APP 状态标签依次显示"按压中 → 回位中 → 就绪"，计数 +1；
3. 快速连点按钮：第二次应在 3 秒后才执行（间隔锁生效）。

### 6.2 角度（行程）调节测试

1. 滑杆 V1 从 15 开始，每次 +5，空载观察舵盘转角；
2. 确认你需要的转角：**行程 = 转角差（度）× 摇臂半径（mm）× π / 180**。
   例：摇臂半径 12mm、角度差 25° → 行程约 5.2mm（符合 3~5mm 目标）。

### 6.3 真实按键测试（重要，先看易错点）

1. 目标先用**不重要的按键**（如路由器复位键、台灯开关）或垫一块橡皮模拟；
2. 从最小角度开始，逐步 +2°，找到"**刚好能触发按键**"的角度；
3. 记住这个角度值，它就是这台设备的最优按压角。

### 6.4 通过标准

- 局域网内点击"按压"，设备 2 秒内完成"按下-保持-回位"；
- 计数准确、断电重开计数不丢失；
- 角度/保持时间调节立即生效（无需重启）。

## 七、本阶段易错点汇总

1. **版本**：必须用新版 Blynk IoT（蓝闪电），Legacy 已停服；
2. **配网频段**：手机和 ESP32 必须在同一 2.4G WiFi；双频合一路由器会导致配网失败或频繁掉线；
3. **Template ID 填错**：编译不会报错，但 APP 找不到设备，核对是否复制完整（TMPL 开头）；
4. **重新配网**：换 WiFi 时按住 BOOT 键再通电 3 秒进入配网模式；
5. **Blynk 云偶发慢**：中国大陆访问海外云偶尔延迟 1~3 秒属正常；断线后固件自动重连，无需操作；
6. **保持时间不要超过 2 秒**：长按 4 秒会触发电脑强制关机；
7. **APP 找不到设备**：确认手机与 ESP32 同一 WiFi；仍不行则用串口监视器看日志，把输出发给我排查。
