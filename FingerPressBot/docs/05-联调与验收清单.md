| 项目 | 测试方法 | 通过标准 |

### 测试 5：力度校准（1~3N 验收，关键步骤）

**方法一（推荐，有弹簧秤）**：
1. 用弹簧秤（或厨房电子秤读数 × 0.1 换算牛顿：100g ≈ 1N）顶在按压头上；
2. APP 触发按压，读取按压瞬间最大力；
3. 力偏大 → 减小按压角度（每次 1°）；力偏小 → 增大角度（每次 1°）；
4. 直到峰值力落在 **1~3N** 区间，记录最终角度值。

**方法二（无工具手感法）**：
1. 从最小角度开始，每次 +2° 试按；
2. 找"**刚好能稳定触发按键**"的角度（触发成功率 100%）；
3. 再 +2° 作为余量，观察按键回弹是否干脆（回弹慢说明压太深，回调 1°）。

| 通过标准 | 说明 |
|---|---|
| 峰值力 1~3N | 超过 3N 会加速键帽老化 |
| 触发成功率 100%（20 次） | 有失败说明角度不足或对位偏移 |
| 按键回弹正常 | 无"卡键""不回弹"现象 |

> **安全红线**：按压保持时间保持默认 400ms；任何时候保持时间超过 4 秒，电脑电源键会触发强制关机，务必不要调大。

## 三、常见问题排查表

| 症状 | 可能原因 | 排查/解决 |
|---|---|---|
| 设备不上线 | WiFi 密码错/频段不符 | 重新配网，确认 2.4G；串口看日志 |
| 频繁掉线 | 双频合一/信号弱 | 固定 2.4G SSID；设备靠近路由器测试 |
| 舵机不动 | 信号线没接对/供电不足 | 检查橙线接 GPIO13；换 2A 电源 |
| 舵机抖动/抽搐 | 供电电流不足、共地不良 | 检查 GND 共地；确认电源 ≥2A；线材加粗 |
| 舵机异常发烫 | 堵转（按压头卡住）/角度过大 | 断电检查机械干涉；减小按压角度 |
| 按压无力/触发失败 | 角度不足、力臂 R 太大、对位偏移 | 逐步加大角度；换 R10/R12 档；重新对位 |
| 按压过猛/按键回弹慢 | 角度过大、保持时间过长 | 减小角度；保持时间恢复 400ms |
| 按一下触发两次 | 回位后按键未弹起又压到 | 加大回位角度（待机角调大）；检查按压头是否卡键帽 |
| 计数不增加 | Blynk 面板 V4 未绑定 | APP 检查 Label 组件引脚是否为 V4 |
| 计数断电丢失 | NVS 未保存 | 固件默认已保存；确认固件为 v1.0 最新版 |
| 机身翻倒 | 配重不足、按压力矩过大 | 配重加到 ≥300g；减小角度；粘贴固定 |
| 按压头滑脱 | M3 螺丝松动 | 螺纹加厌氧胶/生料带；换热熔螺母 |
| Blynk 反应慢（1~3 秒） | 海外云网络波动 | 属正常；等待自动恢复；紧急用 Web 兜底页 |
| 设备响应但状态标签不变 | APP 面板刷新延迟 | 下拉刷新；Label 重新绑定 V3 |
