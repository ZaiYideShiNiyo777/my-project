# 01 - 物料采购清单（BOM）

> 本清单用于阶段 0 采购。**现在请你做的事**：打开淘宝/拼多多/京东，按下面的清单下单，预计 1 周内到货。
> 同时可先阅读 `04-3D建模尺寸需求书.md` 开始建模，两条线并行不耽误。

## 五、下单建议

1. **一次买齐电子物料**（第 1~10 项），同一家店购买省运费；ESP32 和舵机在"电子元件店"类店铺更专业。
2. 到货后**立即做两件事**：
   - 用游标卡尺测量舵机四个安装孔的中心距，记录到 `04-3D建模尺寸需求书.md` 的"实测记录"位置（建模要用）；
   - 手机充电头 + 数据线给 ESP32 通电，看板载 LED 是否亮（确认不是坏件）。
3. **到货验收**：ESP32 板载 LED 通电即亮；舵机用手轻转输出轴能转动且松手回弹（舵机通电前可自由转动属正常）。

## 六、易错点提醒（本阶段重点）

1. **舵机型号**：务必是"MG90S 金属齿轮"，SG90 塑料齿轮在反复按压下很快扫齿报废。
2. **数据线**：只充电不能传数据的数据线会让烧录失败且难排查，买的时候问清楚。
3. **充电头**：5V/1A 的旧充电头不够用（舵机动作瞬间电流可达 1A 以上），2A 是底线。
4. **别买多**：ESP32 开发板 1 块即可（坏了再说），舵机买 2 个（一个备用）。
