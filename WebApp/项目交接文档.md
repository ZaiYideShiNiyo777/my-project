## 1. 项目概况

- **项目名称**：全行业可信信息聚合平台（移动端极简暗色版，Web App）
- **核心定位**：聚合全行业实时信息，通过「白名单数据源 + 自动化信誉评分（NLP）+ 人工兜底」三级过滤保证信息可信度，暗色极简 UI，以刷信息流为第一使用场景
- **PRD 文档**：`d:\LinShi\开发文档\WebApp.txt`（GBK 编码，共 11 节；换电脑时记得带上）
- **UI 铁律**：纯黑底 `#000000` + 唯一强调色 `#60a5fa`；Lucide 描边图标；点击热区 ≥ 44x44pt；无阴影无渐变

## 2. 技术栈（PRD 强制选型）

| 层 | 技术 |
|---|---|
| 前端 | Vue 3 (Composition API) + Vite + Pinia + Vue Router (Hash) + `lucide-vue-next` + Axios |
| 后端 | Python FastAPI + SQLAlchemy |
| 数据库 | 开发用 SQLite（`backend/dev.db`）；生产用 PostgreSQL + Redis（docker-compose 已配好） |
| 部署 | Docker + Nginx（`docker-compose.yml` + `deploy/nginx.conf`） |

## 5. 本地启动方法

**后端**（终端 1）：
```powershell
cd backend
pip install -r requirements.txt
python -m app.seed        # 初始化/更新种子数据（幂等，可重复执行）
uvicorn app.main:app --port 8000
```

**前端**（终端 2）：
```powershell
cd frontend
npm install
npm run dev               # 端口 5173，/api 自动代理到 localhost:8000
```

**验证接口**：`http://localhost:8000/api/health`、`/api/feed`、`/api/categories/tree`（FastAPI 自带文档 `http://localhost:8000/docs`）

**类型检查与构建**：
```powershell
cd frontend
npx vue-tsc --noEmit
npm run build
```

## 6. 关键开发约定（改数据/加功能前必读）

1. **数据三处同步**：任何新闻/分类数据改动必须同步三处
   - 后端种子脚本 `backend/app/seed.py`
   - SQL 迁移 `backend/sql/002_seed.sql`
   - 前端兜底数据 `frontend/src/mock/fallback.ts`
2. **可信度底线**：`credibility_score < 0.6` 的数据前端永远收不到（后端过滤 + 前端兜底同样遵守）；新增来源须进白名单 `trusted_sources`（`credibility.py` 从库读取自动生效）
3. **真实性铁律**：扩充新闻基于真实报道过的主题，不虚构事件；来源可考
4. **新分类图标**：必须同步 `frontend/src/utils/iconMap.ts` 登记 Lucide 图标名（注意：lucide 的 `Home` 图标已更名为 `House`）
5. **兜底策略**：后端离线时前端自动降级为 mock 数据，并显示「离线演示数据 · 后端未连接」提示，不允许出现「网络异常」报错
6. **UI 铁律**：暗色 token（`--bg-base` 等 CSS 变量）、Lucide 描边图标、44x44 热区、无阴影渐变

## 8. 常见问题速查

| 现象 | 原因/处理 |
|---|---|
| 页面一直「加载中」卡死 | feed store 死锁已修复；若复发检查 `stores/feed.ts` 的 `refresh()` 开头是否释放 loading |
| 离线时仍提示网络异常 | 检查 `mock/fallback.ts` 是否被改动、`http.ts` 竞速超时逻辑 |
| 新增分类后抽屉图标不显示/点击无响应 | 检查 `iconMap.ts` 是否登记图标（Lucide 名称拼写） |
| 后端 5432/6379 端口占用 | Docker 环境未启动或本地已有 PostgreSQL/Redis，确认 `docker compose up -d postgres redis` |
| 前端 5173 被占用 | Vite 会自动换端口，按终端提示访问 |
